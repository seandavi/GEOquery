# Clear the GEOquery download cache

Remove all entries from the persistent download cache (see
[`geoCache`](http://seandavi.github.io/GEOquery/reference/geoCache.md)).

## Usage

``` r
clearGEOCache()
```

## Value

`NULL`, invisibly.

## See also

[`geoCache`](http://seandavi.github.io/GEOquery/reference/geoCache.md)
